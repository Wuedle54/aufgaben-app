# aufgaben-app
Einfache Aufgabenliste mit reinem HTML, CSS und JavaScript. Zum Anschauen `index.html` im Browser öffnen.

## Tests

Voraussetzung: [Node.js](https://nodejs.org) ist installiert.

Einmalig einrichten:

```
npm install
npx playwright install chromium
```

Tests starten:

```
npm test
```
